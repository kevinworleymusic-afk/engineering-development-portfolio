# Engineering Development Planning Templates

[Master calendar](../README.md) · [Category chooser](CATEGORY_CHOOSER.md)

These templates extend the Critical Listening lesson-planning approach across the remaining development pathways. Use them in this order:

1. [Monthly Development Calendar](01-monthly/MONTHLY_DEVELOPMENT_CALENDAR.md) — set the month’s sequence and intended evidence.
2. [Weekly Development Plan](02-weekly/WEEKLY_DEVELOPMENT_PLAN.md) — assign pathway-level objectives to specific days.
3. [Daily Development Log](03-daily/DAILY_DEVELOPMENT_LOG.md) — turn one selected focus into an immediate work plan.
4. [Focused Implementation Block](03-daily/FOCUSED_IMPLEMENTATION_BLOCK.md) — define the objective, stages, evidence, and stopping rule without imposing an arbitrary duration.

The user may choose only broad inputs—for example, **“Develop Automotive: measurement planning; maintain DSP: Python testing.”** The detailed plan should then be populated from the current calendar, prior evidence, available tools, and the relevant project roadmap.
