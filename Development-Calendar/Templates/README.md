# Engineering Development Planning Templates

[Master calendar](../README.md) · [Category chooser](CATEGORY_CHOOSER.md)

The non-listening pathways use a deliberately light planning hierarchy:

1. [Monthly Development Calendar](01-monthly/MONTHLY_DEVELOPMENT_CALENDAR.md) — set the month’s sequence and intended evidence.
2. [Weekly Development Plan](02-weekly/WEEKLY_DEVELOPMENT_PLAN.md) — assign pathway-level objectives to specific days.

Daily work is documented directly in the relevant project, code, report, portfolio page, calendar entry, or professional-contact record. Separate daily logs remain specific to the trial-based [Critical Listening system](https://github.com/kevinworleymusic-afk/technical-ear-training/tree/main/templates).

The user may choose broad inputs—for example, **“Develop Automotive: measurement planning; maintain DSP: Python testing.”** The weekly plan should translate them into objectives and evidence without creating unnecessary administrative work.
