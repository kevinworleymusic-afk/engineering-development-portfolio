# DSP & Software Calendar Gateway

[Master calendar](../README.md) · [Open the full DSP & Software Calendar](../Calendars/dsp-and-software.md)

The detailed calendar combines audio-software development with DSP implementation and validation. It connects Python application work, Pure Data prototypes, MATLAB projects, testing, documentation, simulation, and planned embedded-DSP development.

## Calendar Flow

1. Set the week's DSP and software processes in the [DSP & Software Calendar](../Calendars/dsp-and-software.md).
2. Populate scheduled dates with the detailed feature, implementation, test, documentation, simulation, or validation objective.
3. Add only a short linked DSP & Software entry to each applicable day on the [master calendar](../README.md).
4. Link completed days to source code, patches, tests, results, documentation, or validation evidence.
