# DSP Calendar Gateway

[Master calendar](../README.md) · [Open the full DSP Calendar](../Calendars/dsp.md)

The detailed DSP calendar remains within the Engineering Development Portfolio and connects work across Pure Data, MATLAB, planned SigmaStudio development, simulation, and validation.

## Calendar Flow

1. Set the week's DSP processes in the [DSP Calendar](../Calendars/dsp.md).
2. Populate scheduled dates with the detailed implementation or validation objective.
3. Add only a short linked DSP entry to each applicable day on the [master calendar](../README.md).
4. Link completed days to code, patches, results, or validation evidence.
