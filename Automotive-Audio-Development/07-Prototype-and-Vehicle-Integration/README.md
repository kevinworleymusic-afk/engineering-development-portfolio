# 07 — Prototype & Vehicle Integration

## Function
Assemble, commission, troubleshoot, and refine hardware, software, DSP, controls, and measurements as one working vehicle system.

## Knowledge being developed
Integration sequencing; signal-flow verification; commissioning; fault isolation; gain structure; interface testing; installation constraints; tuning handoff; issue documentation.
