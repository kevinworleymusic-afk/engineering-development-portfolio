# DSP, Electronics & Audio Software

**Audio DSP · Python · MATLAB · Real-Time Prototyping · Electronics · Analysis Automation**

My implementation-oriented audio work spans **MATLAB and Python analysis, digital signal processing, real-time signal-flow prototyping, audio software tools, electronics foundations, and development toward embedded/automotive audio workflows**.

The strongest thread through this work is using code and signal processing as engineering tools: to analyze audio, implement repeatable transformations, automate validation, prototype signal paths, and connect mathematical behavior to what a listener ultimately hears.

This page is my targeted portfolio for **DSP, audio-software, embedded-audio, test-automation, electronics-adjacent, and technical development roles**.

## Core Strengths

- MATLAB audio/DSP work involving filtering, convolution, discrete-time systems, delay, nonlinear processing, distortion, harmonics, and spatial/mid-side processing.
- Python development for audio-file analysis, listening tools, engineering training tools, data handling, and repeatable reporting.
- Real-time node-based DSP prototyping in Pure Data.
- FFT/spectral analysis and practical connection between DSP changes and perceptual outcomes.
- Graduate electronics foundation including circuits, analog signal flow, test equipment, troubleshooting, safety, repair, and soldering.
- Development habits centered on documentation, validation, limitations, and incremental implementation rather than black-box tool use.
