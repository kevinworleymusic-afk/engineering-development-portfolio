# DSP, Electronics & Audio Software

This portfolio view presents my work through a signal-processing and implementation lens: audio DSP, MATLAB and Python analysis, real-time signal-flow prototyping, electronics foundations, software tooling, and development toward embedded-audio workflows.

## What this page is for

This page is intended for DSP, audio-software, embedded-audio, test-automation, electronics-adjacent, and technical development teams.

## Selected evidence

### Audio File Report
[Repository](https://github.com/kevinworleymusic-afk/audio-file-report) for tested WAV validation and analysis, including metadata reporting, stereo FFT plots, diagnostics, corruption checks, and saved or interactive output.

### Engineering Trainer Flashcards
[Repository](https://github.com/kevinworleymusic-afk/engineering_trainer_flashcards) implementing a command-line engineering knowledge trainer with JSON-driven question banks, selectable categories and question types, randomized sessions, answer evaluation, and scoring.

### Technical Listening Trainer
[Repository](https://github.com/kevinworleymusic-afk/technical-listening-trainer) combining controlled audio processing with configurable listening exercises, validated filters, answer management, and CSV analytics.

### Real-Time DSP and Tuning-Workflow Prototype
[Pure Data implementation](https://github.com/kevinworleymusic-afk/capture-to-reproduction-audio-study/blob/main/docs/01_Real-Time_DSP_Prototype_in_Pure_Data.md) covering node-based playback, delay, filtering, gain, test signals, low-frequency routing, and output protection.

### MATLAB Audio DSP Projects
[Project collection](../../Projects/Coding-and-Audio-Software/MATLAB-Projects/) covering filtering and discrete-time systems, convolution, tempo-synchronized delay, nonlinear processing, clipping, harmonics, THD, distortion, and mid-side/spatial processing.

### Audio Electronics Fundamentals
[Workbook and development area](../../Projects/Coding-and-Audio-Software/Audio-Electronics-Fundamentals-Workbook/) building from prior coursework in circuits, analog signal flow, test equipment, troubleshooting, safety, repair, and soldering toward more explicit calculation and simulation work.

### Audio Weaver and DSP Development
[Development pathway](../../Projects/Coding-and-Audio-Software/Audio-Weaver-and-DSP-Development/) documenting tutorial review and accessible-tool DSP exercises while avoiding claims of direct Audio Weaver implementation before that work is completed.
